# Gator - RSS Feed Aggregator CLI

A command-line RSS feed aggregator built with Go that allows you to follow RSS feeds, browse posts, and aggregate content from multiple sources.

## Prerequisites

Before running Gator, make sure you have the following installed:

- **Go 1.24.4 or later** - [Download from golang.org](https://golang.org/dl/)
- **PostgreSQL** - [Download from postgresql.org](https://www.postgresql.org/download/)

## Installation

Install Gator using Go's built-in package manager:

```bash
go install
```

This will install the `gator` command to your `$GOPATH/bin` directory. Make sure your `$GOPATH/bin` is in your `$PATH` environment variable.

## Configuration

Gator requires a configuration file to connect to your PostgreSQL database. Create a config file at `~/bootDev/.gatorconfig.json`:

```json
{
  "db_url": "postgres://username:password@localhost:5432/gator_db?sslmode=disable",
  "current_user_name": "your_username"
}
```

### Database Setup

1. Create a PostgreSQL database:
```sql
CREATE DATABASE gator_db;
```

2. Run database migrations using goose:
```bash
# Install goose if you haven't already
go install github.com/pressly/goose/v3/cmd/goose@latest

# Run migrations to create the necessary tables: users, feeds, posts, feed_follows
goose -dir sql/schema postgres "your_connection_string" up
```

## Usage

Gator provides several commands for managing RSS feeds and users:

### User Management
- `gator register <username>` - Create a new user account
- `gator login <username>` - Switch to an existing user
- `gator users` - List all users (current user is marked with *)

### Feed Management
- `gator addfeed <name> <url>` - Add a new RSS feed
- `gator follow <url>` - Follow an existing feed
- `gator unfollow <url>` - Stop following a feed
- `gator following` - List feeds you're following
- `gator feeds` - List all available feeds

### Content Browsing
- `gator browse [limit]` - Browse posts from your followed feeds (default limit: 2)
- `gator agg <duration>` - Start aggregating feeds (e.g., `gator agg 30s`)

### System
- `gator reset` - Reset the database (delete all users and feeds)

## Examples

```bash
# Register a new user
gator register john

# Add a feed
gator addfeed "Tech News" "https://example.com/rss"

# Follow the feed
gator follow "https://example.com/rss"

# Browse recent posts
gator browse 5

# Start aggregating feeds every 30 seconds
gator agg 30s
```

## Development

This project uses:
- **goose** for database migrations
- **sqlc** for type-safe database query generation
- **PostgreSQL** as the database
- **Go modules** for dependency management

To run migrations after schema changes:
```bash
goose -dir sql/schema postgres "your_connection_string" up
```

To regenerate database code after query changes:
```bash
sqlc generate
```
